# PROJECT_STATUS — הכיסא

## מה היה קיים (שלב 0)
- אין פרויקט משחק קיים, אין Backend, אין Database ואין מערכת AI. הפרויקט הוקם מאפס בתיקייה `hakise/`.
- Node 24 / npm 11 זמינים.

## החלטות טכנולוגיות
| תחום | בחירה | למה |
|---|---|---|
| Frontend | React 18 + TypeScript + Vite | פשוט, מהיר, יציב להרצה מקומית |
| עיצוב | Tailwind v4 + שכבת CSS משלנו (`index.css`) | Utilities ללייאאוט, רכיבי משחק מותאמים |
| גרפים | Recharts | גרפים פשוטים וקריאים |
| State | Zustand (שכבת UI דקה) + מנוע טהור | ה-GameState הוא מקור האמת; ה-store רק מחזיק ומעביר למנוע |
| Backend | אין (MVP) | המשחק רץ כולו בדפדפן. SQLite לא נדרש בשלב הזה |
| שמירה | localStorage, אוטומטית בסוף כל תור | אפס תשתית, עובד אופליין |
| AI | מנוע Narrative מבוסס תבניות + ממשק Provider | דטרמיניסטי, בלי אינטרנט; ניתן לחבר LLM בעתיד |
| בדיקות | Vitest | בדיקות למנוע הסימולציה |

## מה נבנה
ראו `ROADMAP.md` לסטטוס לפי שלבים, `ARCHITECTURE.md` למבנה.

## בעיות שזוהו / מגבלות ידועות
- קריקטורות הן SVG פרוצדורלי (ניתנות להחלפה באיורים).
- ה-AI הוא כרגע מערכת חוקים + תבניות טקסט; אין קריאה ל-LLM (ראו TODO ב-`src/engine/ai/provider.ts`).
